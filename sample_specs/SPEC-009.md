# Equipment Specification

## General

- Manufacturer: FastScan
- Model: FS-1000
- Equipment Type: High Speed 3D Inspection System
- Measurement Principle: 3D Laser Profilometry
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Width: 1200 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Z Measurement Range | 0 ~ 1000 μm |
| Accuracy | ±3.0 μm |
| Repeatability | ±1.5 μm |
| Z Resolution | 1 μm |
| X Resolution | 100 μm |
| Y Resolution | 100 μm |
| Maximum Line Speed | 1000 mm/s |
| Sampling Rate | 20 kHz |

## Defect Inspection

| Item | Specification |
|---|---|
| Minimum Detectable Defect | 100 μm |
| Defect Types | Large Scratch, Crack, Edge Defect |

## Interface

- PLC
- Ethernet/IP
- MES

## Environment

- Operating Temperature: 5 ~ 45 °C
- Humidity: 20 ~ 85 %RH

## Safety

- Laser Class: Class 3R
- Interlock: Supported

## Notes

Designed for high-speed inspection of wide electrode rolls.
