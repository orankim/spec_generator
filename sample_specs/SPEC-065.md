# Equipment Specification

## General

- Manufacturer: WideScan
- Model: WS-1500
- Equipment Type: Surface Inspection
- Measurement Principle: 2D Laser Triangulation
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 1500 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 50 μm |
| Accuracy | ±0.5 μm |
| Repeatability | ±0.3 μm |
| Z Resolution | 0.2 μm |
| Measurement Speed | 600 mm/s |

## Defect Inspection

| Item | Specification |
|---|---|
| Minimum Detectable Defect | 20 μm |
| Defect Types | Scratch, Contamination |
| Classification | Not Supported |

## Optical System

- Sensor: 2D Laser
- Light Source: Laser

## Interface

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Laser Class: Class 2
- Emergency Stop: Supported

## Notes

Very wide inspection width (1500 mm) but a narrow Z measurement range (0~50 um) — optimized for flat, wide electrode lines rather than deep-defect profiling.
