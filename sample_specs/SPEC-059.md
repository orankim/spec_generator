# Equipment Specification

## General

- Manufacturer: ProfileLaser
- Model: PL-300
- Equipment Type: 3D Profile Inspection
- Measurement Principle: 3D Laser Profilometry
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode Surface Profile
- Maximum Electrode Width: 300 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 300 μm |
| Accuracy | ±0.9 μm |
| Z Resolution | 0.2 μm |
| Measurement Speed | 550 mm/s |

## Defect Inspection

- Not Supported

## System

- Camera: CMOS
- Light Source: Laser
- Data Output: Ethernet
- PLC Interface: Supported
- MES Interface: Supported

## Environment

- Operating Temperature: 5 ~ 40 °C
- Humidity: 20 ~ 85 %RH

## Safety

- Laser Safety: Class 2
- Emergency Stop: Supported

## Notes

Performs continuous inline three-dimensional surface profiling of battery electrodes.
