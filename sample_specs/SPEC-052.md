# Equipment Specification

## General

- Manufacturer: TotalInspect
- Model: TI-1000
- Equipment Type: Inline Electrode Thickness and Surface Defect Inspector
- Measurement Principle: 3D Laser Profilometry
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 1000 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 800 μm |
| Accuracy | ±0.8 μm |
| Repeatability | ±0.4 μm |
| Z Resolution | 0.1 μm |
| Measurement Speed | 700 mm/s |

## Defect Inspection

| Item | Specification |
|---|---|
| Minimum Detectable Defect | 2 μm |
| Defect Types | Scratch, Pinhole, Particle, Surface Defect |
| Classification | Supported |

## Optical System

- 3D Sensor: Laser
- Light Source: Laser

## Interface

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Laser Class: Class 2
- Interlock: Supported
