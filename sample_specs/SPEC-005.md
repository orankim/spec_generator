# Equipment Specification

- Manufacturer: LaserMetrix
- Model: LP-500
- Equipment Type: Inline Electrode Profile Inspection System
- Measurement Principle: 3D Laser Profilometry
- Inspection Mode: Inline

| Y Resolution | 50 μm |
