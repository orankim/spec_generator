# Equipment Specification

## General

- Manufacturer: ConfocalTech
- Model: CT-100
- Equipment Type: Thickness Inspection
- Measurement Principle: Confocal
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 500 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 150 μm |
| Accuracy | ±0.3 μm |
| Repeatability | ±0.15 μm |
| Z Resolution | 0.05 μm |
| Measurement Speed | 150 mm/s |

## Defect Inspection

- Not Supported

## Optical System

- Sensor: Confocal
- Light Source: White LED

## Interface

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Emergency Stop: Supported

## Notes

Designed for continuous inline electrode thickness measurement using confocal displacement sensing.
