# Equipment Specification

## General

- Manufacturer: RapidLaser
- Model: RL-900
- Equipment Type: Thickness Inspection
- Measurement Principle: 2D Laser
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 900 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 200 μm |
| Accuracy | ±3 μm |
| Z Resolution | 0.8 μm |
| Measurement Speed | 2000 mm/s |

## Defect Inspection

- Not Supported

## System

- Camera: CMOS
- Light Source: Laser
- Data Output: Ethernet
- PLC Interface: Supported
- MES Interface: Supported

## Environment

- Operating Temperature: 5 ~ 40 °C
- Humidity: 20 ~ 85 %RH

## Safety

- Laser Safety: Class 2
- Emergency Stop: Supported

## Notes

Designed for continuous inline electrode thickness measurement.
