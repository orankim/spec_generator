# Equipment Specification

## General

- Manufacturer: PrecisionEdge
- Model: PE-250
- Equipment Type: 3D Profile Inspection
- Measurement Principle: Interferometry
- Inspection Mode: Offline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 350 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 90 μm |
| Accuracy | ±0.08 μm |
| Repeatability | ±0.04 μm |
| Z Resolution | 0.02 μm |
| Measurement Speed | 20 mm/s |

## Defect Inspection

- Not Supported

## Optical System

- Sensor: Interferometer
- Light Source: White Light

## Interface

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Emergency Stop: Supported

## Notes

Ultra-precise offline profile inspection for R&D sample analysis; low throughput by design.
