# Equipment Specification

- Manufacturer: EdgeScan Pro
- Model: ES-800
- Equipment Type: Edge Inspection
- Measurement Principle: Laser + Vision
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode Edge
- Maximum Electrode Width: 800 mm

## Defect Inspection

| Item | Specification |
|---|---|
| Minimum Detectable Defect | 2 μm |

- Camera: CMOS

- Data Output: Ethernet
- PLC Interface: Supported
- MES Interface: Supported

## Environment

- Operating Temperature: 5 ~ 40 °C
- Humidity: 20 ~ 85 %RH

## Safety

- Laser Safety: Class 2
- Emergency Stop: Supported
