# Equipment Specification

## General

- Manufacturer: CoatingInspect
- Model: CI-400
- Equipment Type: Coating Thickness Inspection System
- Measurement Principle: OCT
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode Coating
- Maximum Width: 500 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Thickness Range | 5 ~ 400 μm |
| Accuracy | ±1.5 μm |
| Repeatability | ±0.7 μm |
| Thickness Resolution | 0.5 μm |
| Measurement Rate | 1 kHz |

## Defect Inspection

| Item | Specification |
|---|---|
| Defect Types | Coating Non-uniformity, Void |
| Minimum Detectable Defect | 20 μm |

## Optical System

- Light Source: Near Infrared
- Wavelength: 930 nm

## Interface

- Ethernet
- OPC-UA
- PLC

## Environment

- Operating Temperature: 10 ~ 40 °C

## Notes

Optimized for inline coating thickness and coating uniformity inspection.
