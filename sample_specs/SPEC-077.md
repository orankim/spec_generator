# Equipment Specification

## General

- Manufacturer: ThickOnly
- Model: TO-150
- Equipment Type: Thickness Inspection
- Measurement Principle: Laser
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 550 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 220 μm |
| Accuracy | ±0.6 μm |
| Repeatability | ±0.3 μm |
| Z Resolution | 0.12 μm |
| Measurement Speed | 320 mm/s |

## Defect Inspection

- Not Supported

## Optical System

- Sensor: Laser
- Light Source: Laser

## Interface

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Laser Class: Class 2
- Emergency Stop: Supported

## Notes

Inline thickness inspection only — surface defect inspection is not supported on this model.
