# Equipment Specification

## General

- Manufacturer: WideThickness
- Model: WT-1000
- Equipment Type: Thickness Inspection
- Measurement Principle: Optical
- Inspection Mode: Inline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 1500 mm

## Measurement Performance

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 300 μm |
| Accuracy | ±1 μm |
| Z Resolution | 0.2 μm |
| Measurement Speed | 700 mm/s |

## Defect Inspection

- Not Supported

## System

- Camera: CMOS
- Light Source: LED
- Data Output: Ethernet
- PLC Interface: Supported
- MES Interface: Supported

## Environment

- Operating Temperature: 5 ~ 40 °C
- Humidity: 20 ~ 85 %RH

## Notes

Designed for continuous inline electrode thickness measurement.
