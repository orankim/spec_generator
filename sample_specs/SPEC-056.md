# Equipment Specification

- Manufacturer: ChromaScan
- Model: CC-200
- Equipment Type: Thickness Inspection
- Measurement Principle: Chromatic Confocal
- Inspection Mode: Offline
- Measurement Type: Non-contact

## Inspection Target

- Target: Battery Electrode
- Maximum Electrode Width: 350 mm

| Item | Specification |
|---|---|
| Measurement Range (Z) | 0 ~ 80 μm |
| Accuracy | ±0.08 μm |
| Repeatability | ±0.04 μm |
| Z Resolution | 0.01 μm |
| Measurement Speed | 15 mm/s |

- Not Supported

- Sensor: Chromatic Confocal

- PLC: Supported
- MES: Supported

## Environment

- Operating Temperature: 10 ~ 40 °C
- Humidity: 20 ~ 80 %RH

## Safety

- Emergency Stop: Supported

Ultra-high precision offline chromatic confocal gauge for thin coating/electrode thickness.
